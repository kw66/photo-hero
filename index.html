    玩法说明

    选择怪物后战斗，击败怪物获得胶卷。用胶卷拍照鉴定现实物品，照片会转化为装备属性。装备格默认全部生效，越清楚、有趣、主体明确的照片越容易得到好装备。

    形态和 Boss

    点击勇者头像可切换形态。每种形态击杀 20 个怪物后升到 Lv.2。Boss 胜利后会出现三选一奖励，奖励会影响胶卷或照片鉴定价值范围。

    API 和隐私

    API Key、接口地址和模型名只保存在当前浏览器本地。照片鉴定会把压缩后的图片发送到你配置的图文模型接口。
