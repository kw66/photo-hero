## ✨ 这是什么

《图片勇者》是一款纯前端 H5 魔塔式图文爬塔游戏。玩家可以在两种完全等价的模式之间随时切换：

- 📷 **照片勇者**：拍桌面小物、日用品、工具、玩具，让它们变成装备。
- 🎨 **画图勇者**：画现实物品、幻想道具或自己的创意装备，把简笔画变成装备。
- **随时切换**：只影响下一次消耗的胶卷/画布和装备格图标，已经生成的装备不会改变。
- **完整一局**：40 层爬塔、Boss、隐藏救援层、装备词条、勇者形态、怪物/NPC/词条图鉴，以及通关和失败两种结局。

## 🎯 核心体验

- **图片变装备**：现实小物和玩家手绘都能进入鉴定台。
- **图文模型先看图，本地规则再收口**：主体、质量、价值、属性和词条都由本地统一计算。
- **魔塔式推进**：普通层可选 1 到 3 个怪物挑战，Boss 层和奖励强敌提供三选一奖励。
- **胶卷 / 画布循环**：击败怪物、救援 NPC、选择 Boss 奖励都能补充后续鉴定资源。
- **装备词条技能化**：部分词条会在战斗中显示冷却、计数和本场累计加成。
- **隐藏救援层**：每 10 层区间都有隐藏事件，救出老人、商人、小偷、公主可以拿到关键奖励。
- **冒险手册**：内置玩法说明、战斗机制、怪物、Boss、NPC、勇者形态和装备词条图鉴。
- **公共体验鉴定台**：默认可以免配置试玩，也可以切换到自己的 OpenAI-compatible 图文模型 API。

## 🚀 快速开始

公开网页：

```text
https://kw66.github.io/photo-hero/
```

第一次游玩建议这样开始：

1. 打开网页后先领取开局三张胶卷/画布，全部选中后进入塔内。
2. 默认 `体验` 鉴定台无需填写地址、模型和 API Key；公共额度繁忙时，可以切换到自己的接口。
3. 点击空装备格。照片勇者会拍照或上传图片，画图勇者会打开画布。
4. 点击鉴定，等待模型识别并生成装备。
5. 进入楼层后点击怪物卡牌选择目标，再点击战斗。
6. 打开 `冒险手册` 可以查看拍照/画图规则、战斗机制和图鉴。

## 鉴定规则

- 照片优先看真实实拍、主体清楚、大小合适；网图、截图、素材图、电商图和大场景会被压低。
- 画图先看主体能不能认出来，再看线条连贯、结构完整、配色和整体观感；一团线或看不出主体的图不会稳定出装备。
- 图片里的文字不作为装备依据，命名和属性主要看可见主体。
- 鉴定失败、取消、超时或解析失败不会消耗胶卷/画布，也不会清空已经拍好或画好的图。

## 玩法概览

### 胶卷与画布

- 每次普通鉴定消耗 1.0 胶卷/画布。
- 击败怪物、救援 NPC、Boss 奖励会补充后续鉴定资源。
- 分解装备会按品质返还资源：普通 0.3、稀有 0.5、史诗 0.7、传说 0.9。
- 已装备的装备可以重鉴定，消耗为 `1.0 - 分解返还`，方便玩家低成本重试。

### 战斗与成长

- 普通层通常有 3 张怪物卡牌，可选 1 到 3 只怪物挑战，也可以取消选择。
- 多选怪物可以更快获得资源，但多个敌人会一起行动，风险更高。
- 护盾每场战斗刷新，先于生命承伤。
- 回复在受击后触发，吸血在勇者进攻后触发。
- 击败第 40 层魔王可以通关；如果救出隐藏 4 的公主，则进入真结局。

### 隐藏救援层

每 10 层区间有一个隐藏层。触发后会先进入救援事件，左右是看守怪物，中间是 NPC，救出后拿奖励。

- 👴 老人：所有勇者形态经验 +2
- 🧑‍💼 商人：胶卷/画布 +2.0
- 🕵️ 小偷：获得宝石，攻击、防御、速度 +1
- 👸 公主：生命回满，并开启真结局条件

## 公共体验与 API

- **体验模式**：默认开玩，走 Cloudflare Worker 公共鉴定台。
- **自定义 / 预设 API**：填自己的接口和 Key，配置只保存在本机浏览器。
- **可用性前提**：需要支持图片输入、OpenAI-compatible `/chat/completions` 和浏览器跨域请求。

## 本地运行

Node 只用于本地静态预览和回归脚本，不参与 GitHub Pages 玩家访问。默认 `体验` 模式也会走 Cloudflare Worker；只有调试本地代理时，才需要在页面加载前显式设置 `window.PHOTO_HERO_EXPERIENCE_PROXY_BASE_URL`。

```powershell
npm start
```

然后打开：

```text
http://localhost:3000
```

常用检查：

```powershell
npm run qa:review
node scripts\appraisal-lite-regression.cjs
node scripts\experience-proxy-regression.cjs
```

## 项目结构

- `index.html`、`styles.css`、`app.js`：页面、样式和核心逻辑
- `assets/`：音频、勇者、怪物、NPC、奖励图标、README 截图
- `docs/`：鉴定回归记录
- `scripts/`：回归和 QA 脚本
- `workers/`：Cloudflare Worker 公共鉴定台
- `server.js`：本地静态预览服务
