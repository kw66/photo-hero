## ✨ 这是个什么游戏？

《照片勇者》是一款纯前端 H5 图文爬塔游戏。

玩家打开网页后，可以拍照或上传现实物品，并用自己填写的多模态大模型 API Key 进行“鉴定”。AI 会根据照片里的物品、画面质量和物品特征生成装备描述，游戏再把它转化成可控的数值和词条。

也就是说，你桌上的杯子、风扇、钥匙、玩具、零食、文具，都可能变成勇者的装备。

## 🧠 核心特色

- 📷 **拍照变装备**：用手机相机或相册上传现实物品，生成属于你的照片装备。
- 🤖 **AI 交互式探索**：每次鉴定都由图文大模型参与，装备结果来自“现实物品 + AI 理解 + 游戏规则”。
- 🗼 **40 层爬塔战斗**：每层选择打几个怪，想多拿胶卷就要承担更高战损。
- 🎞️ **胶卷资源循环**：击败怪物攒胶卷，胶卷继续换照片鉴定机会。
- 🧩 **形态与 Boss 奖励**：勇者形态可升级，Boss 后有三选一奖励，构成轻量成长路线。
- 🛡️ **数值简单但有爽点**：攻击、防御、速度、生命、护盾、回复、吸血组成战斗核心。
- 🌐 **无需后端**：GitHub Pages 静态网页即可运行，API Key 只保存在玩家自己的浏览器里。

## 🚀 开始游玩

公开网页：

```text
https://kw66.github.io/photo-hero/
```

进入游戏后：

1. 点击 `API配置`。
2. 选择一个支持图片输入的模型预设，或填写自定义 OpenAI-compatible 接口。
3. 填入你自己的 API Key。
4. 用“图文模型测试”确认接口可用。
5. 点击空装备格，在详情栏拍照并鉴定。
6. 装备自动生效，开始爬塔。

## 🔑 API 说明

本项目没有服务器接收或保存玩家 Key。所有配置都只保存在浏览器 `localStorage`。

照片鉴定接口需要满足：

- 支持图片输入 / 多模态 / vision；
- 支持 OpenAI-compatible `/chat/completions`；
- 允许 GitHub Pages 网页进行浏览器 CORS 直连。

如果接口不支持浏览器跨域，或者模型不支持图片输入，就会出现测试或鉴定失败。

## 🕹️ 玩法简述

### 装备

- 开局有 3.0 张胶卷。
- 每次拍照鉴定消耗 1.0 张胶卷。
- 装备栏最多 10 件装备，默认全部生效。
- 分解装备会按品质返还少量胶卷。
- 游戏更鼓励现实实拍物品，而不是网图、截图或虚拟装备图。

### 战斗

- 一层通常有 3 只怪，可以选择挑战其中 1 到 3 只。
- 每击败 1 只怪物获得 0.1 胶卷。
- 多打怪能更快攒胶卷，但多个敌人会一起攻击。
- 第 10、20、30、40 层是封门 Boss。
- 第 25、35、38 层是奖励强敌，打赢后同样会出现三选一奖励。

### 属性

- **生命**：归零后只能重开。
- **攻击**：决定对怪物造成的伤害。
- **防御**：抵消普通攻击。
- **速度**：单位时间进攻次数。
- **护盾**：每场战斗刷新，先替生命承伤。
- **回复**：挨打后回血。
- **吸血**：勇者进攻后回血。


```text
http://localhost:3000
```

