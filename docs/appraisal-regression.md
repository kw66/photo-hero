# 鉴定模块回归表

这张表用于发布前和每次调整提示词、解析器、压缩参数、去重逻辑、品质规则、特殊词条规则后做回归。目标不是让模型“听话地给高分”，而是确认照片装备的结果符合游戏体验：鼓励现实实拍、主体清楚、有趣互动；抑制网图、截图、AI 图、虚拟装备图和同一物体重复刷装备。

## 当前规则快照

- 输入：浏览器把照片压缩后，以 OpenAI-compatible `/chat/completions` 的 `image_url` 形式发送给用户配置的多模态模型。
- 模型职责：只判断图片主体、现实性、大小、画面质量、属性倾向、特殊词条倾向和一句玩家描述。
- 本地职责：计算最终分数、品质、属性、特殊词条、重复物品、分解返还，不直接相信模型给出的最终数值。
- 默认分数区间：`5-20`，Boss 奖励可提高最低分和最高分。
- 品质：普通 `5-12`，稀有 `13-16`，史诗 `17-20`，传说 `21+`。
- 属性价值：生命上限 `1`，攻击 `5`，防御 `6`，速度 `12`，护盾 `3`，吸血 `8`，回复 `10`。
- 生命装备效果：生命上限 `+1` 视为一份属性点，同时首次装备会额外回复 `+2` 当前生命，但界面不额外展示这条机制。
- 分解返还：普通 `0.2`，稀有 `0.4`，史诗 `0.6`，传说 `0.8` 胶卷。
- 特殊词条：只在语义很强、分数足够、不是虚拟/网图/截图类输入时出现；现实卡片、贴纸、屏幕只按载体本身评价，不按图案里的幻想武器评价。
- 去重：只有已经成为装备的物品参与重复判断；分解后不再对比。可能冲突时用两张图再次调用视觉模型判断是否为同一个现实物体。

## 通过标准

- 可装备的小型现实物体应稳定得到合理属性，不应出现“描述说回复/防御，结果却只加生命”这类语义和属性冲突。
- 分数需要有区分度：普通随手拍多为普通/稀有，清楚、有趣、主体突出的实拍物才应靠近史诗，传说需要 Boss 奖励或非常强的实拍质量。
- 杂乱背景、小主体、模糊、反光、过暗应明显降分。
- 网图、截图、游戏装备图、AI 渲染图、透明背景素材、电商白底图应为无效或普通低分载体，不应成为高分幻想装备。
- 大到不能随身装备的主体，如汽车、房子、天空、街景、整间屋子，应不给装备属性。
- 同一现实物体的多张照片不能同时装备；同类但不同实体可以装备。
- 失败、超时、取消、JSON 解析失败都不能消耗胶卷，也不能锁住战斗或装备操作。

## 建议的发布前抽样

- 现实清晰小物：30 张。
- 现实但质量差或杂乱：20 张。
- 食品、植物、玩具、卡片、屏幕、包装：20 张。
- 网图、截图、AI 图、电商图、素材图：15 张。
- 超大物体、场景、人像、动物：10 张。
- 重复物体与同类不同物体：5 组以上。

每批至少记录：最终分数分布、品质分布、属性分布、特殊词条出现率、失败率、重复拦截率。若史诗/传说集中出现在网图或杂乱图，优先调整质量上限；若描述与属性冲突，优先调整语义匹配和本地属性分配，而不是只改提示词。
